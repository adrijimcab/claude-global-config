# `stop-the-line-on-the-second-occurrence` — evidencia completa

Texto literal movido desde `~/.claude/rules/00-owner-mandates.md` (sección «STOP THE LINE ON THE
SECOND OCCURRENCE») al aplicar el prompt-audit aprobado por el dueño. La forma vinculante (la regla
en sí, más breve) sigue viviendo en `00-owner-mandates.md`. A diferencia de las 11 claves del sistema
`~/.claude/rules/promoted-rules.md`, esta NO es una clave promovida al contrato global — es prosa
propia del dueño sin un archivo de evidencia previo, así que este archivo se crea ahora, siguiendo la
misma convención de nombres, para no perder el detalle al condensar la regla.

- **`stop-the-line-on-the-second-occurrence`** — This is NOT what the failure-capture loop already
  did. That loop forces a lesson to be RECORDED, and PROMOTED to the contracts on recurrence — it
  produces text, and text has now measurably failed: `measurement-failure-is-not-a-zero` recurred an
  EIGHTH time with its rule already promoted to both agent contracts and anchored in the parity gate;
  `unmeasured-rationale-stated-as-fact-in-brief` is at twelve; `bounded-search-read-as-absence` at
  five. Every one had binding text. Every one happened again. So promotion no longer closes an
  incident: **closing it requires a mechanism that makes the repeat impossible**, and until that
  mechanism exists nothing else advances.
