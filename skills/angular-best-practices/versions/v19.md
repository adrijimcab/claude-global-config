## Stable and usable

- Standalone is the default: never write `standalone: true` (UR `19.0.0-standalone-declarations`;
  migration `explicit-standalone-flag` added `standalone: false` where NgModules declare components).
- Signals: `signal`, `computed`; signal inputs/outputs/model `input()`, `output()`, `model()` and signal
  queries `viewChild`/`viewChildren`/`contentChild(ren)` are stable (`@publicApi 19.0`, `A19:roadmap.md:50`).
- Control flow `@if`/`@for`/`@switch`, `@defer` (stable since 18), `@let`, `typeof` in templates.
- Builder: `@angular-devkit/build-angular:application` (esbuild); `ng new` uses Karma + Jasmine through
  `@angular-devkit/build-angular:karma`; change detection with zone.js
  (`provideZoneChangeDetection({ eventCoalescing: true })`).
- Event replay (`withEventReplay()`), `NgOptimizedImage`, typed reactive forms.

`toSignal`/`effect` in DP are widely used and change little, but they still changed between 19 and 20
(effect timing; `afterRender` rename): if the project already uses them, keep them consistent and expect the
20 migration to touch them; do not introduce new uses of EXP APIs. angular-eslint 19.8.1 has no
`no-experimental`/`no-developer-preview` rule, so this is a review item.

## Deprecated in 19

`APP_INITIALIZER`, `ENVIRONMENT_INITIALIZER`, `PLATFORM_INITIALIZER` (use `provideAppInitializer()` /
`provideEnvironmentInitializer()`; migration `provide-initializer`); `effect({ allowSignalWrites })` (no-op,
remove it); `Router.errorHandler`; `ExperimentalPendingTasks` renamed `PendingTasks` (migration `pending-tasks`);
`HttpClientModule`, `HttpClientTestingModule`, `RouterTestingModule` (use `provideHttpClient()`,
`provideHttpClientTesting()`, `provideRouter()`).

## Removed or changed behaviour in 19

`this.` no longer reaches template reference variables; `BrowserModule.withServerTransition` removed;
`KeyValueDiffers.factories` removed; `fakeAsync` flushes pending timers by default (`{ flush: false }` for the
old behaviour); TestBed rethrows `ApplicationRef.tick` errors; effects run during change detection, so tests
that relied on Promise timing need `await fixture.whenStable()`/`detectChanges()`.

## Idiomatic v19 component

```ts
import { ChangeDetectionStrategy, Component, computed, input, output } from '@angular/core';

export interface OrderLine {
  readonly id: string;
  readonly name: string;
  readonly price: number;
  readonly quantity: number;
}

@Component({
  selector: 'app-order-summary',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: { class: 'order-summary' },
  template: `
    @if (lines().length === 0) {
      <p>No items.</p>
    } @else {
      <ul>
        @for (line of lines(); track line.id) {
          <li>{{ line.name }} × {{ line.quantity }}</li>
        }
      </ul>
      <p>Total: {{ total() }}</p>
      <button type="button" (click)="checkout.emit()">Checkout</button>
    }
  `,
})
export class OrderSummaryComponent {
  readonly lines = input.required<readonly OrderLine[]>();
  readonly checkout = output<void>();
  protected readonly total = computed(() => this.lines().reduce((sum, line) => sum + line.price * line.quantity, 0));
}
```

No `standalone: true`, no `effect`/`linkedSignal`/`resource` (DP/EXP in 19), explicit OnPush, suffix file name.
