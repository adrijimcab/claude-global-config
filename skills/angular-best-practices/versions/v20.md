# Angular 20 — the full source for a v20 project

Measured 2026-10-06 from `angular/angular` branch `20.3.x` (v20.3.33), `angular/angular-cli` branch `20.3.x` and
`npm view`. Citation key as in `v19.md` (`A20:`, `C20:`, `UR:`).

Angular 20 has AI rules (`A20:adev/src/context/best-practices.md`, 56 lines) but does NOT ship them inside
`@angular/core` (that starts in 21.0.0), so this file plus the matrix in `~/.claude/rules/fe-angular.md` is the
source. The MCP tool `get_best_practices` (CLI 20.1+) serves a bundled copy.

## Stabilised in 20.0 (usable)

`effect`, `linkedSignal`, `afterEveryRender` / `afterNextRender` / `afterRenderEffect`, `toSignal`,
`toObservable`, incremental hydration (`withIncrementalHydration()`), route-level render mode
(`provideServerRendering(withRoutes(serverRoutes))`), template HMR (`A20:roadmap.md:125,130`;
CHANGELOG 20.0.0). Zoneless: developer preview in 20.0-20.1, **stable from 20.2** as
`provideZonelessChangeDetection()` (`@publicApi 20.2`, `A20:roadmap.md:55`).

## New in 20

`ng new` writes suffix-less files (`app.ts`, `app.html`, `app.spec.ts`) and follows the new 2025 style guide
(`A20:style-guide.md:24-47`; CLI migration `previous-style-guide` keeps old projects on the 2016 naming);
`provideBrowserGlobalErrorListeners()` in generated config; `@angular/build:application` as the builder;
experimental Vitest builder `@angular/build:unit-test` (`A20:guide/testing/experimental-unit-test.md:1-5`);
`ng mcp` (CLI 20.1.0); `ng new --ai-config` (20.2.0); template `**`, tagged template literals, `in`, `void`;
fetch options on HttpClient/httpResource (20.1-20.2); `Router.currentNavigation` signal (20.2);
`BootstrapContext` (20.3).

## Still experimental in 20 — avoid by default

`resource()`/`rxResource()`/`httpResource()` (EXP until 22.0; renames in 20: `request` → `params`,
`rxResource` `loader` → `stream`, `ResourceStatus` enum → string unions); the Vitest builder; MCP experimental
tools (`onpush_zoneless_migration`, `find_examples`, `modernize`); `withViewTransitions` (DP in every major).
Gate: angular-eslint `no-experimental` and `no-developer-preview`.

## Deprecated in 20

`NgIf`/`NgFor`/`NgSwitch` (use `@if`/`@for`/`@switch`; `A20:packages/common/src/directives/ng_if.ts:160-161`);
`TestBed.get`; `InjectFlags`; `Router.getCurrentNavigation()` (use `currentNavigation`); `provideAnimations*`
(20.2, removal planned for v23; use `animate.enter`/`animate.leave`).

## Removed or renamed in 20

`afterRender` → `afterEveryRender`; `provideExperimentalZonelessChangeDetection` →
`provideZonelessChangeDetection`; `provideExperimentalCheckNoChangesForDebug` → `provideCheckNoChangesConfig`;
`TestBed.flushEffects()` → `TestBed.tick()`; `ng-reflect-*` attributes off by default
(`provideNgReflectAttributes()` to restore); `provideServerRouting` → `withRoutes`; template properties named
`in`/`void` need `this.`.

## Updating to 20 (from 19)

`ng update @angular/core@20 @angular/cli@20`. Migrations it runs (`A20:packages/core/schematics/migrations.json`):
`inject-flags`, `test-bed-get`, `control-flow-migration`, `document-core`, `router-current-navigation` (20.2),
`add-bootstrap-context-to-server-main` (20.3). CLI migrations: `replace-provide-server-rendering-import`,
`replace-provide-server-routing`, `update-module-resolution` (`bundler`), `previous-style-guide`,
`use-application-builder`, `remove-default-karma-config` (20.2).

Update-guide actions (UR L2553-2775): Node >= 20.11.1 (and within the engines range above), TypeScript >= 5.8;
`moduleResolution: "bundler"` (automatic); rename `afterRender`; rename resource options; `TestBed.get` →
`TestBed.inject`; stop relying on `ng-reflect-*`; tests: uncaught listener errors are rethrown
(`rethrowApplicationErrors: false` only as a last resort, and then as a finding), animations flush with change
detection; templates respect parentheses (`(foo?.bar).baz`); `redirectTo` combined with `canMatch` now errors.

Optional `ng generate @angular/core:<name>` (same set as 19): `control-flow`, `inject`, `signal-input-migration`,
`signal-queries-migration`, `output-migration`, `self-closing-tag`, `cleanup-unused-imports`.

## Project conventions in 20

- Naming: keep what the project has. A project migrated from 19 keeps `x.component.ts` (the
  `previous-style-guide` migration pins it); a new 20 project uses `x.ts`.
- `changeDetection: OnPush` is written explicitly (Default is still the default).
- The official 20 rules say no arrow functions or regular expressions in templates
  (`A20:adev/src/context/best-practices.md:49-50`): move them to `computed()` or a method.
- Karma + Jasmine remain the generated test setup; the Vitest builder is experimental.

## Idiomatic v20 component

```ts
import { ChangeDetectionStrategy, Component, computed, effect, inject, input, linkedSignal } from '@angular/core';

import { RecentSearches } from './recent-searches';

@Component({
  selector: 'app-search-panel',
  changeDetection: ChangeDetectionStrategy.OnPush,
  templateUrl: './search-panel.html',
})
export class SearchPanel {
  private readonly recent = inject(RecentSearches);

  readonly options = input.required<readonly string[]>();
  /** Resets to the first option whenever the options change; the user may still pick another. */
  protected readonly selected = linkedSignal(() => this.options()[0]);
  protected readonly hasSelection = computed(() => this.selected() !== undefined);

  constructor() {
    // A side effect that leaves Angular: persisting the choice. Never used to copy state.
    effect(() => {
      const choice = this.selected();

      if (choice !== undefined) this.recent.remember(choice);
    });
  }
}
```

`linkedSignal` and `effect` are stable from 20.0; `resource`/`httpResource` are not used (EXP until 22).
